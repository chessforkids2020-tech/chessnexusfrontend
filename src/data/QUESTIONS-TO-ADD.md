# Questions to add to the Help Center

Write your questions here — one per line is enough. Don't worry about the
format, grouping, or writing answers: paste them in however they come out of
your head and I will turn them into the answered set.

## How to write them

Just the question is fine:

```
how do i cancel a class
what happens if a student misses a class
can i change my coach
how do i see which students didn't practise
```

If you already know the answer, or the answer isn't obvious from the app, add
it after a dash — that saves me guessing:

```
how do i cancel a class - go to Schedule, click the slot, Cancel. The batch chat gets a notice automatically.
```

If two questions mean the same thing, list them both. Different people ask the
same thing in different words, and the matcher gets better the more phrasings
it has for one answer.

## What I'll do with them

1. Group them by audience (coach / player) and topic.
2. Write the answers, checking each one against what the code actually does —
   not what it's supposed to do.
3. Merge with the 146 answers already in the bank, dropping duplicates.
4. Tell you which ones I could NOT answer from the code, so you can fill those
   in rather than have me invent something plausible.
